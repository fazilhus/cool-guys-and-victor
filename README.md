# cool-guys-and-victor
Dungeon Crawler with deckbuilding

Godot engine provides support for building for a number of platforms (Windows, Android etc)

To make a game build one would need to have Godot Engine executable and game source code downloaded locally.Then one should follow official Godot [documentation](https://docs.godotengine.org/en/latest/tutorials/export/exporting_projects.html)
